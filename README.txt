CLEVERZUHAUSE – WEBSITE
========================
1. ZIP entpacken.
2. index.html lokal öffnen, um die Seite anzusehen.
3. Vor einer öffentlichen Veröffentlichung Impressum und Datenschutz korrekt ausfüllen.
4. Affiliate-Links erst nach Zulassung und nach den Regeln des jeweiligen Partnerprogramms ergänzen.
5. Für Amazon PartnerNet brauchst du anschließend eine öffentlich erreichbare URL; eine lokale HTML-Datei reicht dafür nicht.
